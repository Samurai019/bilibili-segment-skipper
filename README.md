# Bilibili 视频片段标记与自动跳过 (Segment Skipper for Bilibili-Evolved)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Bilibili--Evolved%20v2-fb7299.svg)](https://github.com/the1812/Bilibili-Evolved)

为 Bilibili 视频标记指定片段（如片头、片尾、广告赞助、闲聊废话等），在播放时自动跳过。专为 **Bilibili-Evolved v2** 深度定制，设置项无缝融入 Evolved 设置面板，控制按钮像素级对齐播放器底栏。

---

## ✨ 核心特性

- ✂️ **自由多片段标记**：单个视频支持标记任意数量的跳过片段，自动按时间排序管理。
- ⚡ **快捷打点（盲操支持）**：
  - <kbd>[</kbd>：捕获当前播放时间为起点
  - <kbd>]</kbd>：捕获当前播放时间为终点
  - <kbd>\</kbd>：一键保存片段
- 🎨 **Bilibili-Evolved 深度集成**：
  - 设置面板自动注册至 **Evolved 设置 ➔ 组件 ➔ 视频**，自适应深色模式与主题色。
  - 控制按钮内嵌在播放器控制栏右侧（清晰度按钮前），经真实渲染尺寸精准校准，绝无错位或沉底。
  - **防抢跑等待机制**：等待播放器核心按钮（清晰度/倍速）就绪后再平滑渲染，杜绝骨架黑屏期孤立闪烁。
- 📊 **进度条区间高亮**：已启用的跳过区间自动在 B 站视频进度条上渲染粉色半透明标记。
- ⏭️ **自动跳过与撤销机制**：视频播放进入区间时自动瞬移跳过，顶部轻量提示并附带「撤销」按钮（支持 12 秒跳过休眠）。
- 💾 **按视频精准持久化**：支持普通视频多 P（`BVxxxx_pX`）以及番剧分集（`EPxxxx`），数据本地持久化，换 P 自动切换。
- 📦 **配置导入与导出**：支持将片段数据导出为 JSON，便于备份与他人共享。

## 📥 安装使用指引

### 作为 Bilibili-Evolved 用户组件安装（推荐）

1. 下载本仓库中的 [`bilibili-segment-skipper.component.js`](./bilibili-segment-skipper.component.js)。
2. 打开 B 站任意视频页面，点击页面左侧或顶部的 **Bilibili-Evolved 设置齿轮图标**。
3. 进入左侧的 **「组件」** 页面。
4. 点击底部的 **「本地 / 安装用户组件」**（或「代码导入」）。
5. 选择下载的 `bilibili-segment-skipper.component.js` 文件（或粘贴代码）。
6. 点击确定后**刷新网页**即可生效。

## ⚙️ 设置选项 (Bilibili-Evolved 面板)

在 Bilibili-Evolved 设置面板中，可对以下项目进行独立开关：
* **启用自动跳过**（默认开启）
* **跳过时显示提示框 (支持撤销)**（默认开启）
* **启用打点快捷键 ([ 起点, ] 终点, \\ 保存)**（默认开启）
* **在进度条上高亮显示跳过片段**（默认开启）

## 🎮 操作说明

1. **呼出面板**：点击播放器控制栏右下角的 `⏭` 图标，即可弹出轻量控制小窗。
2. **添加片段**：
   - 播到目标起点点击“当前”（或按 <kbd>[</kbd>）；
   - 播到目标终点点击“当前”（或按 <kbd>]</kbd>）；
   - 输入可选标签备注，点击保存（或按 <kbd>\</kbd>）。
3. **管理片段**：
   - 点击 `▶` 快速试听定位起点。
   - 点击 `✓` / `✗` 临时启用或停用某片段。
   - 点击 `✕` 删除片段。
   - 底部支持一键清空、导出至剪贴板或粘贴 JSON 导入。
